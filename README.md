# Rainbow downloads for your phone

Open this page in Chrome while signed in to your Rainbow GitHub account.

- [Download all five screens’ images](https://github.com/josiahscalia5-dev/rainbow-/archive/refs/heads/codex/downloads/Rainbow_Visual_Images.zip)
- [Download all five screens’ gameplay videos](https://github.com/josiahscalia5-dev/rainbow-/archive/refs/heads/codex/downloads/Rainbow_Gameplay_Videos.zip)

Each complete ZIP contains a README_FIRST.md guide. If ChatGPT declines a ZIP, extract it in Android’s Files app and attach the pictures or an MP4 from one screen.

## One screen at a time

Each small image ZIP contains the unchanged approved artwork and four matched pairs of full-size gameplay pictures. The two MP4 links for each screen show Claudia’s retained ride and the unapproved Codex candidate.
