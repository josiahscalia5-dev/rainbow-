## 1. YVO3D Retexture

Sources: docs.scenario.com YVO3D reference (`https://docs.scenario.com/get-started/generation/3d-model-generation/3d-model-generation-yvo3d/index.md`) and `https://help.scenario.com/articles/5785335470-yvo3d-the-essentials`.

- **Inputs:** `model` (required), an existing GLB. `referenceImage` (optional file). The reference image is required when `retexture` (Replace Textures) is on. With it off, the existing textures are kept.
- **Reference image use:** It is generative. The docs describe "newly generated textures" that guide "color, material, and style." `creativity` ranges from 0 ("stays faithful to your reference") to 5 ("allows more imaginative interpretation"). `textureAdherence` "keeps the generated texture closer to the look of your reference image." No source says whether reference pixels are projected directly. Treat it as an AI-generated surface.
- **Geometry:** The help article says it works "without touching the underlying geometry."
- **UVs:** `generateUvs` defaults to `ON` and creates UV maps "when they're missing." Nothing says how existing UVs are handled beyond that.
- **Texture resolutions:** `1K` (default), `2K`, `FAST4K`, `REAL4K`, `ULTIMA8K`. The help article says "up to 8K." Pixel dimensions for each option are not stated.
- **Output format:** GLB. The help article says "Both models export GLB."
- **PBR maps:** Not itemized. The retexture settings include `roughness` (default 1.3, range 0–2). The pricing FAQ says 3D meshes come "with PBR textures," but it does not list the individual maps for YVO3D.
- **Polygon count and file size limits:** Not stated for Retexture. Polycount settings appear only on Image to 3D.

## 2. YVO3D Image to 3D

Sources: docs.scenario.com YVO3D reference and `https://help.scenario.com/articles/5785335470-yvo3d-the-essentials`.

- **Inputs:** `images` (required). One image for a single-view build, or 2–4 photos of the same subject from different angles. With multiple photos, put the front view first. Multi-view always uses the Ultima Prime generator.
- **Output:** GLB. Single-image runs can include texture (`texture`, default on). Multi-view runs are described two ways. The help article and the Known Limitations section say multi-view "never produces texture" and is shape only. The docs' `texture` parameter says "With several photos, the texture is painted from the first (front) view." These two statements conflict. Check the live behavior before relying on either.
- **Polycount:** `polycount` default 100,000, range 1,000–2,000,000. It is ignored for textured single-image models. `smartLowPoly` sets about 48–50,000 faces and costs extra.
- **Texture resolutions:** Same set as Retexture (`1K` to `ULTIMA8K`).
- **Single objects vs. environments:** No source says YVO3D is for whole environments, interiors, or tunnels, and none says it is excluded from them. Every example and tip concerns single props or objects, such as a radio, a mug, or a tree. The tips advise a "clean single photo with the subject well separated from the background." Known Limitations says "cluttered backgrounds" degrade the mesh. The use cases mention "archviz GLB assets," but nothing about spaces. The `insideOut` option adds texture to inner surfaces of hollow meshes, but that is not a statement about interiors.

## 4. MCP setup for Claude Code

Sources: `https://www.scenario.com/features/mcp` and `https://help.scenario.com/en/articles/getting-started-with-the-scenario-mcp-server`.

- **Server URL:** `https://mcp.scenario.com/mcp`
- **Install command for Claude Code:** `claude mcp add --transport http scenario https://mcp.scenario.com/mcp`
- **Auth (OAuth, recommended):** No credentials go in the config. On the first request, a browser opens to scenario.com. Log in and click Authorize. You need a Scenario account.
- **Auth (API key):** Open Settings > Organization > API Keys, then base64-encode `KEY:SECRET` with `echo -n 'YOUR_KEY:YOUR_SECRET' | base64`. Send it as `Authorization: Basic <base64>`. The key needs Editor or Admin role. A read-only key returns `Forbidden` on generation. The help article does not show the exact Claude Code flag for setting this header.
- **Troubleshooting:** For an OAuth 401 or expired token, reconnect. If that persists, run `rm -rf ~/.mcp-auth` and reconnect.
- **Cost:** MCP generations use the same Compute Units as the web app. The help article recommends asking for a dry-run estimate before big jobs.
