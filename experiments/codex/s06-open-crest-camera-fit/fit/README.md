## Reproduction

Run the Blender Python script with the unaltered previous outer-ribbon game geometry export, retained Screen 06 camera states, original art and curve layout. Its `BVHTree` ray samples write the complete skyline and tested depth solutions to `constraints.json`. `survey-and-seats.json` records the matching sampled bank points used in the source. The archived project path constants near the top of `measure.py` can be pointed to the corresponding restored files.
